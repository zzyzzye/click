# ClickFlow 页面平滑滚动设计

## 目标

让 ClickFlow 设置页响应鼠标滚轮和触控板时连续、平滑地上下移动，消除当前
`QScrollArea` 默认的离散跳动感。滚动应保持桌面应用的直接性：新的输入立刻影响
目标位置，停止输入后快速、自然地停稳，而不是形成长惯性拖尾。

## 范围

本次仅处理主窗口中四个设置页的垂直 `QScrollArea`：连点设置、键鼠录制、热键设置
和预设与关于。

不改变页面结构、内容高度、滚动条视觉样式或表单控件的滚轮保护。下拉框与数字输入框
继续忽略滚轮，避免误改设置。

## 方案

新增可复用的 `SmoothScrollArea`，继承 `QScrollArea` 并接管视口的滚轮事件。它持有
一个作用于垂直滚动条 `value` 属性的短时 `QPropertyAnimation`。

- 滚轮输入优先读取像素级增量；没有像素级增量时，再按角度增量换算为平滑位移。
- 每次输入都基于当前动画位置更新一个受滚动范围限制的目标值，不将输入量化为固定行高。
- 动画持续约 160ms，使用缓出曲线追赶目标。新的输入不排队，而是从当前显示位置重设终点，
  从而连续滚动时保持贴手、不会拖尾。
- 没有可滚动余量、水平滚动和非垂直滚轮保持 Qt 默认行为。拖动滚动条、键盘导航及其他
  非滚轮操作继续使用原生 `QScrollArea` 行为。

主窗口创建页面容器时使用该组件，保留现有的 `widgetResizable`、无水平滚动和无边框设置。

## 边界与反馈

当目标触及顶部或底部时，数值会被限制在滚动条范围内，动画只移动到边界，不制造回弹效果。
动画不会处理页面以外的控件；因此不会改变组合框、数值框、按钮或弹窗的交互。

## 测试与验证

自动化测试覆盖：

- 主窗口的每个页面容器均为 `SmoothScrollArea`，且仍禁用水平滚动。
- 离散滚轮输入会启动向正确方向运动的动画，并最终到达计算后的连续目标位置。
- 到达滚动范围边界时，目标和最终位置被正确限制。
- 新的滚轮输入会更新同一个动画的终点，不累积多个待执行动画。
- 既有主窗口、页面和功能测试保持通过。

手动验证 Windows 和 macOS：用普通鼠标滚轮与触控板连续滚动较长页面，确认位移平滑、
连续滚动不滞后、停止后迅速收束，并确认悬停在下拉框或数字框时不误改字段。

## 成功标准

- 设置页滚动不再表现为固定像素或固定行高的离散跳跃。
- 连续滚动跟手、无明显延迟或长惯性。
- 顶部和底部边界稳定，没有超出范围或抖动。
- 既有控件滚轮保护和其他滚动方式不回归。
