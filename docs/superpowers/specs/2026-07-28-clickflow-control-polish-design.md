# ClickFlow 控件细节优化设计

## 目标

优化 ClickFlow 0.2.0 设置页的表单控件质感，重点解决 `QComboBox`
下拉按钮、`QSpinBox` 上下调整按钮和侧边栏外框显得陈旧、笨重的问题。
本次不改变页面结构、字段含义或交互流程。

## 视觉方向

采用 ClickFlow 自有的蓝灰色控件语言，不模仿 Windows 11 或 macOS
原生组件。

- 表单底色：`#ffffff`
- 默认边框：`#cfd5dd`
- 悬停边框：`#9eabc0`
- 焦点强调：`#2563eb`
- 按钮悬停底色：`#edf3ff`
- 禁用文字：`#8a94a3`

整体保持现有白色卡片、浅灰页面和蓝色主操作按钮。新的箭头按钮是细节
层级，不与“开始连点”争夺视觉焦点。

## 下拉框

- 保留右侧下拉操作区，但去掉黑色竖线和系统默认箭头。
- 使用尺寸较小、笔画统一的向下 chevron。
- 操作区默认与输入区域融为一体，不显示独立方框。
- 鼠标悬停时仅显示淡蓝圆角底；控件获得焦点时使用蓝色描边。
- 展开、键盘操作和现有数据绑定保持不变。

## 数值框

- 保留上下两个调整按钮。
- 去掉当前粗黑分隔线和系统默认三角形。
- 上下按钮位于统一的窄操作区，使用小型 chevron。
- 默认状态保持安静；悬停单个按钮时出现淡蓝背景。
- 按下时背景略深，提供明确反馈。
- 直接输入、键盘方向键、鼠标滚轮、数值范围和单位后缀保持不变。

## 侧边栏

- 移除导航列表外围的大矩形边框。
- 侧边栏背景继续使用 `#e9ecf1`。
- 未选中项保持透明；选中项继续使用蓝色圆角底。
- 产品名、版本和导航间距保持不变。

## 实现边界

- 新增一组可复用的代码内矢量箭头资源，避免依赖系统主题和外部图片。
- 控件样式集中在应用级样式表中，不在各页面重复配置。
- 只修改表单控件和侧边栏导航相关样式，不顺带调整卡片、布局或业务逻辑。
- Windows 与 macOS 使用同一套 ClickFlow 控件视觉。

## 验证

- 自动测试确认数值框仍显示步进按钮，且下拉框、数值框使用新的样式资源。
- 现有配置往返、依赖控件、主窗口和平台测试继续通过。
- Windows Debug 构建后进行真实窗口截图，检查默认、禁用和焦点状态。
- 不运行打包脚本，不修改 `dist/`。
