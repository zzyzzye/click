# 键盘连按功能设计

## 目标

在保留现有鼠标连点能力的基础上，为应用增加键盘连按模式。用户可录制一个普通键或带修饰键的组合键，按一次开始/停止热键后，应用按照设定间隔反复发送完整的按下与松开事件。

第一版只允许一个配置选择一种动作：鼠标点击或键盘按键。它不支持按住触发、同时执行鼠标和键盘、保持按键按下或编排动作序列。

## 用户操作

“基础设置”顶部新增动作类型选择：

- 鼠标点击
- 键盘按键

鼠标模式显示现有鼠标设置。键盘模式隐藏鼠标专属设置，并显示“要连按的键”录制框。用户聚焦录制框后直接按下目标键，例如 `A`、`Space`、`Return` 或 `Command+C`。

用户点击开始按钮或按开始/停止热键后，应用校验配置并开始连按。再次点击按钮、再次按开始/停止热键或按紧急停止热键时，连按立即停止。运行期间锁定动作类型、目标按键、间隔和热键设置。

按钮和状态文字跟随动作类型变化：

- 鼠标模式使用“开始连点”“点击执行失败”等文案。
- 键盘模式使用“开始连按”“按键执行失败”等文案。

## 数据模型

在 `ClickProfile` 中新增：

- `InputActionType actionType`：取值为 `MouseClick` 或 `KeyboardPress`，默认 `MouseClick`，保证旧配置行为不变。
- `QString keySequence`：使用 `QKeySequence::PortableText` 格式保存目标键或组合键。

`ClickTypes` 为动作类型增加字符串转换，并在 `toVariantMap`、`fromVariantMap` 和配置摘要中处理新增字段。加载不含新增字段的旧配置时，默认使用鼠标点击模式；缺失的目标按键保持为空。

现有间隔、有限/无限次数、倒计时和热键配置由两种动作共享。鼠标位置、按键类型和抖动半径仅对鼠标动作生效。

## 核心与平台结构

将 `ClickBackend` 从只执行鼠标点击扩展为执行输入动作。对外接口使用动作中立的命名，例如：

```cpp
virtual bool performAction(const ClickProfile& profile) = 0;
```

`ClickController` 继续唯一负责倒计时、精确定时、有限次数计数、停止和状态通知。每次定时触发时，它调用 `performAction`，不复制一套键盘计时控制逻辑。相关成员和方法由 `click` 命名逐步改为 `action` 或 `execution` 命名，使职责与两种动作一致。

macOS 后端根据 `actionType` 分派：

- `MouseClick`：沿用现有鼠标移动、按下、松开实现。
- `KeyboardPress`：将 Qt 按键序列转换为 macOS 虚拟键码和修饰键标志，依次发布一次 key-down 和一次 key-up。

键盘事件必须成对创建和发布。若事件创建或按键转换失败，后端返回 `false`，控制器停止计时并报告失败。停止和退出不需要释放长期按下的键，因为本功能不产生跨周期保持的 key-down 状态。

## 按键范围与校验

第一版支持可映射到 macOS 虚拟键码的单个普通键和单个组合键，包括字母、数字、空格、回车、Tab、Escape、方向键、功能键，以及带 `Command`、`Control`、`Option`、`Shift` 的组合。

以下配置禁止启动：

- 未录制目标按键。
- 仅包含修饰键。
- Qt 按键无法映射为 macOS 虚拟键码。
- 目标按键与开始/停止热键或紧急停止热键在规范化后完全相同。比较时统一使用 `QKeySequence::PortableText` 结果，而不是界面显示文本。

捕获坐标热键只在鼠标固定坐标功能启用时参与冲突校验；当前极简界面未开放该功能。开始/停止和紧急停止热键始终保留，默认分别为 F6 和 F8。

## 错误处理与权限

键盘模拟与鼠标模拟共用 macOS 辅助功能权限检查。未授权时沿用现有授权提示和系统设置入口。

界面层负责在启动前展示具体的配置错误。平台事件创建、转换或发布失败时，后端返回失败，控制器立即停止并显示与当前动作匹配的错误状态。任何失败都不得继续消耗有限次数计数。

## 测试

自动测试至少覆盖：

- 新旧配置的序列化与反序列化，确认旧配置默认进入鼠标模式。
- 单键和组合键以 PortableText 格式保存并恢复。
- 控制器对鼠标和键盘动作均按相同的间隔与次数调用后端。
- 有限次数只在动作成功后递减，执行失败立即停止。
- 空目标键、纯修饰键、不可映射按键和控制热键冲突被拒绝。
- macOS 键码映射覆盖第一版声明支持的按键类别。
- 键盘动作每次产生且只产生一对 key-down/key-up。
- F6 能切换开始和停止，F8 能紧急停止。
- 现有鼠标点击路径与权限拒绝测试继续通过。

平台事件发布难以在普通单元测试中直接观察，因此将按键解析与 macOS 事件发布分离：解析和映射使用纯逻辑单元测试，事件发布通过可替换的窄接口或测试替身验证调用顺序。

## 验收标准

1. 用户能在界面中选择键盘按键模式并录制一个单键或组合键。
2. 按一次开始/停止热键后，前台目标应用按照配置间隔收到重复的完整按键事件。
3. 再次按开始/停止热键、点击停止按钮或按紧急停止热键后，不再产生按键事件。
4. 冲突或无效配置无法启动，并给出明确提示。
5. 重启应用后能够恢复动作类型和目标按键。
6. 原有鼠标连点功能和旧配置保持兼容。
