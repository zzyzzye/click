# ClickFlow v0.5.1

## 新增与改进

- 统一使用 ClickFlow 名称，并添加应用图标。
- 提供 Windows x64 / ARM64、Linux x64 / ARM64 和 macOS Apple Silicon 的 64 位安装包。
- Linux X11 会话支持全局点击与热键。

## 安装与兼容性

- Windows x64 面向 Windows 10/11；Windows ARM64 面向 Windows 11 on Arm。
- macOS 安装包适用于 macOS 14 或更新版本的 M 系列芯片。
- Linux DEB 基于 Ubuntu 24.04，依赖系统 Qt；全局输入需要 X11/Xorg 会话，不支持 Wayland 全局输入。
- 宏录制、回放与目标窗口绑定目前仅 Windows 支持。
- 安装包未进行开发者签名；macOS 安装包未进行 Apple 公证。安装前可核对随附的 SHA-256 文件。

## 配置迁移

- 应用配置路径已改为 ClickFlow/ClickFlow，旧 OpenAI/QtClicker 配置不会自动迁移。升级后请重新检查点击设置和热键。
