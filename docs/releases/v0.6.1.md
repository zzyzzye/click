# ClickFlow v0.6.1

本版本包含 0.6.0 的功能与稳定性改进，并修复 Linux 系统 Qt 6.4 下的构建兼容问题。0.6.0 的两种 Linux 安装包未构建成功，本次以新标签重新执行五个平台的打包流程。

## 本次修复

- 修复流程按键控件调用 Qt 6.5 才提供的 API，导致 Linux x64 / ARM64 在 Qt 6.4 下无法编译的问题。
- 连点与流程编辑复用单组按键控件，在 Qt 6.4 和较新版本中保持一致的输入行为。
- 回归测试验证多组按键输入只保留第一组、清空按键后同步到流程，不再直接依赖 Qt 6.5 的属性接口。

## 新增功能

- 新增“编排步骤”：组合点击、多点操作、按键、文字和等待，支持复制、排序、撤销、重做及保存流程。
- 流程支持单轮试运行、有限或无限循环、轮间等待、暂停继续，以及步骤和轮数进度。录制内容可作为步骤块加入流程。
- Windows 已安装版本支持应用内下载更新，显示进度，并在确认“重启并更新”后覆盖原安装目录、重新打开软件，保留配置、预设、录制及流程。

## 界面与稳定性改进

- 更新品牌界面、导航图标和页面动效，提供“减少动态效果”选项。
- 修复鼠标悬停数字框或下拉框时页面滚轮不顺畅的问题，避免滚动页面误改参数。
- 简化连点设置，收起高级选项；录制停止后保留草稿，允许先试运行再命名保存。
- 补齐流程空状态、按钮可用状态、未保存提示和执行反馈，压缩顶部布局以适应小窗口。
- 预设列表明确区分“选中”与“正在使用”，修复管理其他预设时误改当前配置关联的问题，并检查配置写入结果。
- 启动前检查按键能力、固定坐标、显示器空隙和已启用的控制热键冲突；倒计时结束及连点运行中复查输入权限和显示器布局。
- 改善录制回放的停止响应，避免大量到期事件长时间占用界面线程。
- 更新仅匹配较新的正式版本及对应架构的准确附件；下载使用 SHA-256 校验，附件失效时引导重新检查。
- 修正 VS Code 的构建与调试配置。

## 安装与兼容性

- 提供五种 64 位安装包：Windows x64 / ARM64、Linux x64 / ARM64、macOS Apple Silicon。
- Windows x64 面向 Windows 10/11；Windows ARM64 面向 Windows 11 on Arm。
- macOS 安装包适用于 macOS 14 或更新版本的 M 系列芯片。支持步骤编排、按键与文字；录制回放及应用内覆盖更新尚未实现。
- Linux DEB 基于 Ubuntu 24.04，依赖系统 Qt 6.4；全局输入需要 X11/Xorg。支持点击、等待及已有的单键范围，组合键、文字、录制及覆盖更新尚未实现，不支持 Wayland 全局输入。
- 宏录制、回放与目标窗口绑定目前仅 Windows 支持。旧录制文件格式保持兼容，编排流程使用独立文件格式。
- 安装包未进行开发者签名；macOS 安装包未进行 Apple 公证。安装前可核对随附的 SHA-256 文件。

## Windows 更新说明

- 旧版本若没有应用内下载更新功能，需要手动安装一次本版本；便携副本和开发目录不支持覆盖更新。
- 仅正式发布的更高版本可被发现，草稿 Release 和同版本不会提示升级。正式 Release 需要包含对应架构安装包及 `.sha256` 文件。
- 下载完成不会立即退出；确认重启更新后，安装器会请求 Windows 管理员授权。更新保留用户数据，不要求重新安装或重启电脑。
- 安装失败会尝试重新打开可用版本，目前没有自动回滚保证。macOS、Linux 仍通过发布页面手动下载安装。

## 验证范围

- 本地已通过 macOS Debug 构建及 11 个 CTest 套件；回归检查使用假输入后端、临时数据、模拟网络和离屏界面，不注入真实桌面输入。
- 五个平台的原生构建与打包结果以本次 GitHub Actions 为准。真实键鼠操作、Windows UAC 与覆盖安装仍需在目标系统验收。
- 覆盖更新端到端测试需要包含该机制的较低已安装版本，以及正式发布的更高版本。详细步骤见 [发布前验收清单](../testing/1.0-acceptance.md)。
